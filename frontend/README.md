# NOX Frontend

Frontend en React para NOX, sistema de microblogging.

## Estructura inicial
- Pantallas de login y registro
- Perfil de usuario (biografía, intereses, edad, origen, etc.)
- Explorar y seguir usuarios

## Requisitos
- Node.js >= 18

## Instalación
1. Instala dependencias:
   npm install
2. Inicia la app:
   npm start

## Scripts
- `npm start`: Inicia la app en modo desarrollo

## Notas
- Consumir la API del backend en `/api`.
